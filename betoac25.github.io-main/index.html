Este site foi desenvolvido como parte de um trabalho acadêmico da disciplina de Web Lab, ministrada pelo professor Pablo Leon, da Universidade de Passo Fundo (UPF). O projeto tem como objetivo aplicar, na prática, os conhecimentos adquiridos durante as aulas, utilizando tecnologias de desenvolvimento web para a criação de uma página funcional e organizada. Durante o desenvolvimento deste trabalho, foram explorados conceitos fundamentais de HTML, CSS e JavaScript, permitindo a construção de uma interface moderna, responsiva e de fácil utilização. Este projeto representa uma oportunidade de colocar em prática as técnicas estudadas ao longo da disciplina e demonstrar as habilidades desenvolvidas na área de desenvolvimento web.
